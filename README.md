## 🚀 How to Run & View

1. **Directly in Browser:** Double-click [index.html](file:///C:/Users/Reshma/.gemini/antigravity/scratch/Reshma-Portfolio/index.html) to open it in Google Chrome, Microsoft Edge, Firefox, or Safari.
2. **With VS Code Live Server:** Right-click `index.html` and click **"Open with Live Server"**.
3. **Deploy to GitHub Pages (Free Hosting):**
   - Push this `Reshma-Portfolio` folder to your GitHub repository `https://github.com/reshma-121/reshma-121.github.io` (or a dedicated portfolio repository).
   - Go to **Settings** > **Pages** > Select `main` branch and `/root` folder.
   - Your site will be live instantly for recruiters!

## 🎨 Design & Features Highlights

- **Recruiter-Friendly Design**: High-contrast typography (Inter font), professional Royal Tech Blue accent color (`#1d4ed8`), clean whitespace, subtle elevations, and distraction-free layout.
- **Strictly Verified Information**: No invented frameworks, metrics, or placeholder links. Every detail matches your profile.
- **"In Progress" Project Status**: Distinct amber badge with a live pulsating indicator for the *Student Performance Analysis & Prediction System*.
- **Vertical Education Timeline**: Displays your B.Tech, HSC, and SSLC records in chronological order.
- **One-Click Copy & Direct Email**: Recruiter can click "Copy" next to your email or click "Send Email Directly" to open their mail client with prefilled details.
- **Responsive Across All Devices**: Adapts smoothly to desktop monitors, laptops, tablets, and smartphones with an accessible hamburger menu.
- **Circular Profile Photo**: Currently loaded with a professional initials avatar placeholder (`images/profile-photo.jpg`). To update it, simply paste your real photo named `profile-photo.jpg` into the `images/` folder!
